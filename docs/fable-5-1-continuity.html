Absence where state was hidden. Strong, imperfect recovery where it was observable.

This is not a single-variable contrast: the observable cell uses a forced tool round and visible text, while the hidden cell is text-only. Within each cell, exact checkpoint and no-state controls use deterministic scoring.

05 · Protocol hardening

The failed pilots are part of the record.

Pre-confirmatory runs found two defects in the harness and measurement budget. Neither was silently rescored.

Wire-format rejection

An internal OpenAI-style tool_calls field leaked into an Anthropic message, producing Extra inputs are not permitted. The serialization boundary now emits only Anthropic role and content; a regression test holds that boundary.

Thinking consumed the answer budget

One exploratory Catalog leg ended at the earlier 256-token ceiling before emitting an answer. Anthropic documents that adaptive thinking shares max_tokens. The confirmatory budget was fixed at 4,096 for continuation legs before these trials began. A 1,024-token pilot was stopped before receipt write; bootstrap generation retained its 512-token allowance.

The schema confound changed the result

An earlier matrix resent a tool schema whose enum contained the checkpoint. The final projected-tail request omits tools entirely. Its observable recovery rate fell from 10/10 to 8/10; Catalog, which never received that schema, was 9/10.

One bootstrap failed closed

One hidden-only bootstrap returned a valid signed thinking block without placing the checkpoint in it. The trial was stopped, retained in the planned denominator, and not replaced.
